player163

A small, no-fuss music player for Linux Mint. Latest version: @LATEST@

Download player163 (.deb)

Double-click the file and choose Install Package.

Updates

Installing the .deb also adds this update source, so new versions show up in Mint's Update Manager like any other update. You can turn it off anytime in Software Sources → Additional repositories.

Set up updates by hand (optional)

If you'd rather add the source yourself and install with apt:

wget -qO- @REPO_URL@/player163.asc | gpg --dearmor | sudo tee /usr/share/keyrings/player163-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/player163-archive-keyring.gpg] @REPO_URL@ stable main" | sudo tee /etc/apt/sources.list.d/player163.list
sudo apt update && sudo apt install player163
